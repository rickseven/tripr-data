Tripr map packs, data release 2026.10.

* Source: Protomaps basemap build 20261008 (OpenStreetMap data, ODbL 1.0), cut per country with Natural Earth outlines.
* 13 PMTiles packs for Singapore, Malaysia, Indonesia, Switzerland, Japan and Germany. See `catalog.json` on the
  project's GitHub Pages site for sizes, zoom levels and `sha256` of every pack.
* The Tripr app downloads these files itself and verifies each `sha256` before use; there is no need to download them
  by hand.
